# ExpenseX – Student Expense Tracker

ExpenseX is a student-friendly expense tracking application that helps users manage their daily income and expenses.

## Features

- User Registration and Login
- Firebase Authentication
- Add Income and Expense Transactions
- View Transaction History
- Edit Existing Transactions
- Dashboard with Expense Summary
- Statistics Screen
- Currency Converter

## Technologies Used

- React Native
- Expo
- JavaScript
- Firebase Authentication
- Cloud Firestore
- React Native Paper
- Frankfurter Currency API
- React Navigation

## Installation and Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/rudharsharma016-tech/ExpenseX.git
   ```

2. Open the project folder:
   ```bash
   cd ExpenseX
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the application:
   ```bash
   npx expo start
   ```
